# Accessibility Review Checklist

| รายการตรวจ | ผ่าน หรือ ไม่ผ่าน | สิ่งที่แก้ |
| :--- | :--- | :--- |
| ข้อความหลักบนพื้นขาว contrast อย่างน้อย 4.5 ต่อ 1 | ผ่าน | กำหนดสีตัวอักษรเป็น #111827 บนพื้นขาว |
| ปุ่มหลักมี contrast เพียงพอ | ผ่าน | ใช้สีพื้นปุ่ม #1E40AF ตัวหนังสือสีขาว (#FFFFFF) |
| ทุกช่องกรอกมี label ที่มองเห็น | ผ่าน | แสดงข้อความ `<label>` เหนือช่องกรอกทุกช่อง |
| ช่องที่บังคับกรอกมีสัญลักษณ์ชัด | ผ่าน | เพิ่มสัญลักษณ์ดอกจันสีแดง (*) ท้ายชื่อ label |
| error ไม่ได้ใช้สีอย่างเดียว มีไอคอนหรือข้อความด้วย | ผ่าน | ใส่ไอคอนเตือน ⚠️ คู่กับข้อความอธิบายวิธีแก้ |
| ลำดับการกด Tab เรียงบนลงล่าง ซ้ายไปขวา | ผ่าน | จัดโครงสร้างลำดับ DOM ให้เรียงตามลำดับสายตา |
| ปุ่มมีชื่อบอกหน้าที่ ไม่ใช่ OK หรือกากบาท | ผ่าน | กำหนดชื่อปุ่มเป็น "บันทึกข้อมูลสินค้า" และ "ยกเลิก" |

## จุดที่ AI ทำพลาดและดำเนินการแก้ไขเอง (อย่างน้อย 2 จุด):
1. **จุดที่ 1:** AI ใช้เฉพาะ `placeholder` ในช่องกรอกข้อมูลสินค้า ทำให้เวลาพนักงานพิมพ์ข้อมูลลงไปแล้วจำไม่ได้ว่าช่องนี้คืออะไร -> **แก้ไขโดย:** เพิ่มข้อความ `<label>` แยกไว้ด้านบนช่องกรอกอย่างชัดเจน
2. **จุดที่ 2:** AI กำหนดสีข้อความ Error เป็นสีเทาอ่อน (`#9CA3AF`) ซึ่งค่า Contrast ไม่ผ่านเกณฑ์ 4.5:1 -> **แก้ไขโดย:** ปรับสีข้อความเตือนเป็นสีส้มเข้ม/น้ำตาล (`#B45309`) เพื่อให้ผู้ใช้มองเห็นได้ชัดเจนและผ่านเกณฑ์ WCAG AA
