# บันทึกการใช้งาน AI (AI Usage Log)

ในโปรเจกต์ระบบ RAG ตอบคำถามระเบียบการศึกษาชิ้นนี้ มีการใช้งาน AI เพื่อช่วยเหลือในการพัฒนา ดังนี้:
1. **การออกแบบสถาปัตยกรรมและโค้ด (Architecture & Code Design):** ใช้ช่วยเหลือในการเขียนโค้ดโครงสร้าง FastAPI, การเชื่อมต่อ ChromaDB, และการตั้งค่า `GoogleGenerativeAIEmbeddings`
2. **การแก้ไขข้อผิดพลาด (Debugging):** ใช้ตรวจสอบและแก้ไข Error 500, รูปแบบชื่อโมเดล Embedding (`models/gemini-embedding-001`), และการจัดการข้อผิดพลาดในการตอบกลับของ API
3. **การจัดเตรียมเอกสาร (Documentation):** ใช้ช่วยร่างโครงสร้างไฟล์ `PROJECT.md` และคู่มือการใช้งานระบบ
