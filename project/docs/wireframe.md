# User Interface & Persona (งานฝั่งผู้ใช้)

## 1. Persona (ผู้ใช้งานระบบ)
* **กลุ่มเป้าหมาย:** นักศึกษาและบุคลากรภายในมหาวิทยาลัย
* **ความต้องการ:** ต้องการค้นหาข้อมูลระเบียบการศึกษา ข้อบังคับ และคู่มือหลักสูตรได้อย่างรวดเร็วและแม่นยำ โดยไม่ต้องอ่านเอกสาร PDF ยาวๆ ทั้งฉบับ
